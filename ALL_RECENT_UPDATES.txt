# Image Recognition for Maintenance - Implementation Guide

## Feature Overview

Maintenance staff can now use **AI-powered image recognition** on complaint attachments to identify replacement parts and quickly search for them. This feature includes:

1. **Automatic Part Detection** - Uses TensorFlow.js COCO-SSD model to identify objects in images
2. **Google Lens Integration** - Direct access to Google Lens for advanced visual search
3. **Shopping Search** - Quick links to find and purchase replacement parts
4. **No API Keys Required** - Runs locally in the browser using TensorFlow.js

## How It Works

### For Maintenance Staff

1. **Dashboard Loads Automatically**
   - All image attachments are automatically loaded and displayed
   - No need to click "Preview" - images are visible by default
   - AI model loads in background for faster recognition

2. **Quick Part Identification**
   - Images are immediately visible for each task
   - Click "Recognize Parts" to identify objects with AI
   - Or use "Google Lens" for advanced visual search

3. **Find Replacement Parts**
   - AI detects parts like "screw", "pipe", "valve", etc.
   - Click "Buy" button to search Google Shopping
   - Direct links to purchase replacement parts

### How AI Recognition Works

1. **Model Loading** (`loadCocoModel()`)
   - Loads TensorFlow.js from CDN
   - Loads COCO-SSD model from CDN
   - Runs once per session

2. **Object Detection** (`detectObjects(imageElement)`)
   - Analyzes image pixel data
   - Identifies objects and their confidence levels
   - Returns top 5 detected objects

3. **Search Integration**
   - `generateGoogleLensUrl()` - Creates shareable Google Lens link
   - `generateGoogleImagesSearchUrl()` - Google Images search
   - `generateShoppingSearchUrl()` - Google Shopping search

## Limitations & Considerations

### Current Limitations

1. **Model Running Locally**
   - First load takes ~2-3 seconds per session
   - Works best with clear, well-lit images
   - ~1-2 second analysis per image

2. **Detection Accuracy**
   - COCO-SSD is trained on 80 common object categories
   - May not identify specialized/technical parts perfectly
   - Confidence varies based on image quality

3. **Internet Requirement**
   - TensorFlow.js scripts loaded from CDN
   - Google Lens/Shopping requires internet
   - Offline recognition not available

### Best Practices

1. **For Best Results**
   - Use clear, well-lit photos
   - Include part in full frame
   - Avoid shadows or glare
   - Use standard angles (top-down or 90Â°)

2. **Fallback to Google Lens**
   - If AI doesn't identify parts well
   - Google Lens usually more accurate for unique parts
   - Can manually refine search

3. **Performance**
   - Model loads automatically on dashboard open
   - Reused across all image analyses in session
   - No performance impact after first load

# MERALCO Integration Guide

## Overview

This integration adds real-time electricity rate forecasting using the official MERALCO (Manila Electric Company) rates for accurate monthly billing predictions in the Philippines.

## What is MERALCO?

MERALCO is the Manila Electric Company, which supplies electricity to Metro Manila and nearby provinces. MERALCO rates change monthly based on various factors including fuel costs, generation expenses, and transmission charges.

## Features

âœ… **Real-Time Rate Fetching**: Automatically retrieves current MERALCO rates monthly
âœ… **Rate Trend Analysis**: Shows if rates are increasing ðŸ“ˆ or decreasing ðŸ“‰
âœ… **Accurate Forecasting**: Calculate tenant electricity bills using real rates
âœ… **AI Integration**: Suggestions include current rate trends
âœ… **Dashboard Sync**: Rates displayed across dashboard, chatbot, and suggestions
âœ… **Fallback Caching**: Uses cached rates if API is unavailable
âœ… **Multi-tenant Safe**: Each tenant gets their own forecasts with latest rates

## Setup Instructions

### Option 1: Using Docker (Recommended)

The Meralco API runs as a separate microservice. Set it up alongside your apartment management system:

1. **Create docker-compose.yml updates** to include Meralco service:

```yaml
services:
  apartment-api:
    # ... existing config
    environment:
      MERALCO_API_URL: http://meralco-ph:5000/rates

  meralco-ph:
    image: ghcr.io/rairulyle/meralco-ph:latest
    container_name: meralco-ph
    ports:
      - "5001:5000"  # Map to port 5001 to avoid conflict with apartment API
    restart: unless-stopped
    environment:
      - TZ=Asia/Manila
```

2. **Update .env** in your apartment management system:

```env
MERALCO_API_URL=http://meralco-ph:5000/rates
```

3. **Start services**:

```bash
docker compose up -d
```

### Option 2: Using Render or Online Host

If you prefer to use the publicly hosted Meralco API (no local setup):

```env
MERALCO_API_URL=https://meralco-ph-api.onrender.com/rates
```

No additional setup needed - the API will automatically fetch rates.


## Troubleshooting

### Payment redirect not working
- Check that `REACT_APP_API_URL` and `SERVER_URL` are correctly set
- Verify PayPal Client ID is correct in frontend .env
- Check browser console for errors

### "Failed to create PayPal payment" error
- Verify `PAYPAL_MODE=sandbox`
- Check that `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET` are correct
- Ensure backend is running and accessible
- Check backend console for detailed error messages

### Payment showing as pending but not approved
- Verify you logged in with the test BUYER account (not business account)
- Check payment_history table in database for transaction status
- Review backend logs for PayPal API responses

### CORS Issues
- Make sure backend CORS is configured to accept frontend URL
- Check that `FRONTEND_URL` is set correctly in backend .env
